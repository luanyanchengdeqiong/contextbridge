## 三、从 0 到 1 的完整实操步骤

1. **选市场**：先看消费力 + 物流可达（东南亚近、物流便宜；北美利润高但物流/合规成本高）。
2. **选平台**：按上表，新手从 Shopee/TikTok Shop 起步最稳。
3. **注册主体与开店**：
   - 个人/个体工商户可开 Shopee、TikTok Shop、速卖通、eBay。
   - 亚马逊主流建议用**企业营业执照 + 双币信用卡**。
   - 准备：手机号、邮箱、法人/身份证件、收款账户（Payoneer / PingPong / 连连等）。
4. **收款（回款）**：海外买家付款 → 多通过 Payoneer / PingPong / WorldFirst 等第三方收款账户 → 提现到国内人民币账户。注意**费率 1% 左右**与**到账周期**。
5. **选品**：用工具（见 `github-tools/` 抓取数据）+ 1688/义乌找货，关注：**轻小、非标、复购高、利润 30%+、避开大品牌的侵权品类**。
6. **上架与 listing 优化**：标题埋关键词、首图点击率、评价与 Q&A；多语言用翻译工具打磨。
7. **物流**：
   - 跨境直发（自发货 / 平台物流如 Shopee SLS、Lazada LGS）。
   - 海外仓 / FBA（亚马逊）：体验好但占资金。
8. **广告投放**：平台站内广告（Shopee 关键词广告、Amazon SP/SB 广告）起步，再考虑 Meta/Google/TikTok 站外引流。
9. **客服与售后**：及时回复、控制退货率（东南亚退货率相对低，欧美/拉美偏高）。
10. **合规**：税务（如欧盟 VAT、美国销售税）、产品认证（CE/FCC/UL 等）、知识产权（不碰仿牌）。

## 四、启动成本测算（真实区间，仅供参考）

| 模式 | 首批资金（参考） | 说明 |
|------|------------------|------|
| **Shopee/TikTok 铺货** | 3000~1 万元 | 以代发为主、囤货少，适合练手 |
| **精品/品牌路线（含广告）** | 2 万~5 万元起 | 含小批量备货 + 测款广告费 |
| **Amazon FBA 精品** | 3 万~10 万元起 | 备货入仓 + 头程物流 + 广告 |
| **Shopify 独立站（含投流）** | 1 万~5 万元起 | 难点在引流，广告预算弹性大 |
| **Dropshipping（无货源）** | 3000~1 万元 | 上手最快、利润薄、物流时效是痛点 |

> 经验：**别一上来就大量备货**。先小批量测款（测出能跑的 SKU），再放大。

## 五、常见坑与风险

- **封店**：侵权、刷单、多账号关联 → 一店一 IP、一卡、一营业执照。
- **侵权**：仿牌、图片盗用 → 选品前查商标/专利（FDA、USPTO、EUIPO 查询）。
- **退货率**：欧美/拉美偏高（服装鞋帽尤甚），要把退货成本算进定价。
- **汇率与回款**：注意汇率波动、收款到账周期（T+N），别让现金流断。
- **平台政策突变**：随时关注后台公告（如佣金率、物流价卡调整）。

## 八、给零基础的最短上手路径

1. 本周：注册 **Shopee / TikTok Shop** 个人店铺（先开一两个）。
2. 用 `github-tools/cross-border-ecommerce-scraper/` 跑几个目标品类的关键词，看价格区间和热卖款，建立选品感觉。
3. 从 1688 找 3~5 个轻小件货源，小量上架测款。
4. 控制首批成本在 **5000 元以内**，先跑通"选品→上架→出单→发货→回款"全流程。
5. 跑通后，再决定是铺货放量，还是转到 Amazon/独立站做精品/品牌。

> 进阶：等你店铺跑起来后，可以用 `python-amazon-sp-api` / `easycb-go` 把订单、库存、报表做成自动化，替代人工。
